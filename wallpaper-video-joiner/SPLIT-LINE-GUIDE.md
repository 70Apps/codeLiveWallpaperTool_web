# 拼合线位置调整说明

## 📍 什么是拼合线？

拼合线是两个视频在输出画面中的分界线位置。通过调整拼合线，可以控制从两个源视频中各自裁剪多少高度的内容。

## 🎯 工作原理

### 视频源裁剪（可调）
- **视频1**：从顶部开始取 **X%** 的高度（X 为滑块值）
- **视频2**：从底部开始取 **(100-X)%** 的高度

### 输出布局
- **上部分**：显示视频1裁剪的内容，占输出高度的 X%
- **下部分**：显示视频2裁剪的内容，占输出高度的 (100-X)%
- **拼合线**：位于输出高度的 X% 位置

## 🎨 视觉效果

### 拼合线指示器
在预览画面上会显示一条蓝色的拼合线，标注"拼合线"文字，实时显示当前位置。

```
┌─────────────────────────────┐
│                             │
│      视频1 (上部X%)         │
│                             │
├─────────────────────────────┤ ← 拼合线 (蓝色)
│                             │
│      视频2 (下部100-X%)     │
│                             │
└─────────────────────────────┘
```

## 🎚️ 滑块控制

### 滑块范围
- **最小值**: 5% （视频1取5%，视频2取95%）
- **默认值**: 50% （视频1取50%，视频2取50%）
- **最大值**: 95% （视频1取95%，视频2取5%）

### 实时反馈
拖动滑块时：
1. 百分比数字实时更新
2. 预览画面实时重绘（裁剪区域改变）
3. 拼合线位置实时移动

## 🔍 技术细节

### Canvas 绘制逻辑

```javascript
// 1. 计算裁剪和输出高度
const ratio = parseInt(splitRatio.value) / 100;
const topHeight = Math.round(outputSize.height * ratio);
const bottomHeight = outputSize.height - topHeight;

// 2. 绘制视频1（源：上部ratio% → 目标：上部分）
const v1SourceHeight = v1Height * ratio;  // 取视频1的前 ratio% 高度
ctx.drawImage(
    video1Element,
    0, 0, v1Width, v1SourceHeight,              // 源：从顶部取 ratio%
    v1OffsetX, 0, v1DrawWidth, topHeight        // 目标：上部分
);

// 3. 绘制视频2（源：下部(1-ratio)% → 目标：下部分）
const v2SourceHeight = v2Height * (1 - ratio);  // 取视频2的后 (1-ratio)% 高度
const v2SourceY = v2Height - v2SourceHeight;    // 从底部往上计算起始位置
ctx.drawImage(
    video2Element,
    0, v2SourceY, v2Width, v2SourceHeight,           // 源：从底部取 (1-ratio)%
    v2OffsetX, topHeight, v2DrawWidth, bottomHeight  // 目标：下部分
);
```

### FFmpeg 滤镜逻辑

```bash
# 视频1：从顶部裁剪 ratio% 的高度，缩放到目标上部分高度
[0:v]crop=iw:ih*ratio:0:0,scale=W:topHeight:force_original_aspect_ratio=increase,crop=W:topHeight[top]

# 视频2：从底部裁剪 (1-ratio)% 的高度，缩放到目标下部分高度
[1:v]crop=iw:ih*(1-ratio):0:ih*ratio,scale=W:bottomHeight:force_original_aspect_ratio=increase,crop=W:bottomHeight[bottom]

# 垂直堆叠
[top][bottom]vstack=inputs=2
```

## 💡 使用场景

### 场景 1: 视频1主导（70:30）
- 视频1取上部70%
- 视频2取下部30%
- 适合：视频1内容更重要，需要更多空间

### 场景 2: 均分显示（50:50）
- 视频1取上部50%
- 视频2取下部50%
- 适合：两个视频同等重要

### 场景 3: 视频2主导（30:70）
- 视频1取上部30%
- 视频2取下部70%
- 适合：视频2内容更重要，需要更多空间

## ⚠️ 注意事项

1. **裁剪比例动态调整**
   - 滑块值直接控制从源视频裁剪的高度百分比
   - 视频1始终从顶部开始裁剪
   - 视频2始终从底部开始裁剪

2. **保持原始比例**
   - 裁剪后的内容会缩放以适应输出高度
   - 保持原始宽高比
   - 使用 contain 模式，可能有黑边

3. **极端比例**
   - 5% 时：视频1只取很小一部分，视频2占主导
   - 95% 时：视频1占主导，视频2只取很小一部分
   - 建议使用 20%-80% 之间的比例

4. **内容完整性**
   - 确保重要内容在裁剪区域内
   - 视频1的重要内容应在上部
   - 视频2的重要内容应在下部

## 🎓 最佳实践

1. **先预览后合成**
   - 调整比例后，点击"更新预览"查看效果
   - 确认裁剪区域包含所需内容

2. **考虑内容分布**
   - 如果视频1的关键内容在上半部分，可以安全使用50%或更高
   - 如果视频2的关键内容在下半部分，可以安全使用50%或更低

3. **测试不同比例**
   - 尝试几个不同的比例
   - 找到最适合内容的裁剪比例

4. **避免裁掉重要内容**
   - 预览时检查是否有重要内容被裁掉
   - 调整比例以包含所有关键信息
