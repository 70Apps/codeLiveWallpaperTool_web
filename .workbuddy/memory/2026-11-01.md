## 新增工具：iPhone Duo 壁纸拼贴 (wallpaper-iphone-duo-collage)
- 路径：`wallpaper-iphone-duo-collage/`（index.html 内联 CSS + script.js + logo.svg）。
- 功能：上传三张壁纸（外屏 1398×2034、内屏竖 1878×2670、内屏横 2670×1878）→ 点击「合成」拼接为一张 2670×6582 长图（外屏→内屏竖→内屏横 从上到下，每屏占满整宽，cover 适配）。
- 导出：PNG / WebP / JPEG；含三屏对应预览与「一张图三屏不同」操作方法（长按→自定义→双指调整）。
- 首页自动发现：home 布局遍历 `layout: web-app` 的 page，用各工具目录的 `logo.svg` 作图标，无需手动改 home-tools-list。
- 注意：`_style.css`（下划线前缀）被 Jekyll 忽略，故本工具样式全部内联在 index.html 的 `<style>` 中，保证独立可用。

## 升级：iPhone Duo 拼贴（同一工具，迭代）
- 需求 1：最大剪切（cover 适配到标准尺寸）保留，已确认满足。
- 需求 2：拼贴布局改为「左上外屏 · 右上内屏竖 · 下方内屏横（整宽）」的 2×网格，画布 3276×4548；各区域放大确保 ≮ 标准（外屏区 1398×2670、内屏竖 1878×2670=标准、内屏横 3276×1878）。
- 需求 3：导出改为 4 张 = 三屏裁剪标准图（外屏/内屏竖/内屏横）+ 拼贴图；支持单张下载（每张一个「下载」按钮），以及一键打包 ZIP（4 张）。
- ZIP 用纯 JS「store」算法（无外部依赖/CDN），含 CRC32 + 标准 local/central/EOCD 结构；已用系统 `unzip -t` 验证无错误、内容字节一致。drawCover 与之前版本一致。
- 健壮性：canvas.toBlob 失败（如旧 Safari 不支持 webp 编码）时回退 toDataURL；thumb 用 webp，不支持时浏览器自动回退 png。
- 验证：node --check 通过；DOM id 与 JS 引用逐一核对；几何与 ZIP 已实测。无 headless 浏览器，未做整页渲染实测。
